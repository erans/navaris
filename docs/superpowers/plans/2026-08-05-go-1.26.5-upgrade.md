# Go 1.26.5 Upgrade Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade Navaris builds from Go 1.26.1 or floating Go 1.26 images to the exact stable Go 1.26.5 patch release.

**Architecture:** `go.mod` remains the source of truth for local and GitHub Actions toolchain selection, while every Go-based Docker stage receives the matching exact image tag. User documentation keeps the release-line requirement `Go 1.26+`; no application code, dependencies, generated files, or workflow structure changes.

**Tech Stack:** Go modules, Go 1.26.5, Docker/BuildKit, GitHub Actions `actions/setup-go@v6`

## Global Constraints

- Set the `go.mod` directive to exactly `go 1.26.5`.
- Pin every active `golang:1.26-bookworm` Docker stage to exactly `golang:1.26.5-bookworm`.
- Do not add a `toolchain` directive.
- Do not upgrade dependencies or intentionally modify `go.sum`.
- Leave `README.md`, `skills/navaris-getting-started/SKILL.md`, and GitHub Actions workflows unchanged.
- Do not modify application behavior, APIs, schemas, release structure, or CI structure.

### Task 1: Pin and verify Go 1.26.5

**Files:**
- Modify: `go.mod:3`
- Modify: `Dockerfile:14`
- Modify: `Dockerfile.navarisd:2,11`
- Modify: `Dockerfile.navarisd-firecracker:2,12`
- Modify: `Dockerfile.test:1`

**Interfaces:**
- Consumes: the approved requirements in `docs/superpowers/specs/2026-08-05-go-1.26.5-upgrade-design.md`
- Produces: an exact Go 1.26.5 build baseline consumed by local Go commands, GitHub Actions through `go-version-file: go.mod`, and all Go-based Docker builds

- [ ] **Step 1: Run the version consistency check and verify the old pins fail it**

Run:

```bash
python3 - <<'PY'
from pathlib import Path

expected = {
    "go.mod": ("go 1.26.5", 1),
    "Dockerfile": ("FROM golang:1.26.5-bookworm AS build", 1),
    "Dockerfile.navarisd": ("FROM golang:1.26.5-bookworm", 2),
    "Dockerfile.navarisd-firecracker": ("FROM golang:1.26.5-bookworm", 2),
    "Dockerfile.test": ("FROM golang:1.26.5-bookworm AS build", 1),
}

for filename, (needle, count) in expected.items():
    actual = Path(filename).read_text().count(needle)
    assert actual == count, f"{filename}: expected {count} occurrence(s) of {needle!r}, found {actual}"

for filename in expected:
    text = Path(filename).read_text()
    assert "golang:1.26-bookworm" not in text, f"{filename}: floating Go 1.26 Docker pin remains"
PY
```

Expected: FAIL on `go.mod` because it still contains `go 1.26.1` rather than `go 1.26.5`.

- [ ] **Step 2: Apply the minimal version replacements**

Run:

```bash
go mod edit -go=1.26.5
python3 - <<'PY'
from pathlib import Path

for filename in (
    "Dockerfile",
    "Dockerfile.navarisd",
    "Dockerfile.navarisd-firecracker",
    "Dockerfile.test",
):
    path = Path(filename)
    old = path.read_text()
    new = old.replace("golang:1.26-bookworm", "golang:1.26.5-bookworm")
    if new == old:
        raise SystemExit(f"{filename}: expected Go 1.26 Docker pin was not found")
    path.write_text(new)
PY
```

Expected changes:

```diff
-go 1.26.1
+go 1.26.5
```

```diff
-FROM golang:1.26-bookworm
+FROM golang:1.26.5-bookworm
```

The Docker replacement occurs once in `Dockerfile`, twice in `Dockerfile.navarisd`, twice in `Dockerfile.navarisd-firecracker`, and once in `Dockerfile.test`.
