> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Align both Claude Code plugin manifests with the upcoming Navaris `v0.2.0` release.

**Architecture:** Keep release metadata synchronized through a minimal two-file JSON value change. A focused parser-based check proves both manifests remain valid JSON and expose exactly the same `0.2.0` plugin version; no runtime or workflow code changes.

- Set `.claude-plugin/plugin.json` top-level `version` to exactly `0.2.0`.
- Set the `navaris-cli` entry in `.claude-plugin/marketplace.json` to exactly `0.2.0`.
- Do not alter any other JSON fields, files, application code, dependencies, or workflows.
- Do not create or push the `v0.2.0` tag in this implementation task.
- Keep historical `v0.1.0` examples and the web package version unchanged.
- Deliver through a pull request, require green CI, and squash-merge before tagging.

### Task 1: Synchronize plugin release metadata

**Files:**
- Modify: `.claude-plugin/plugin.json:4`
- Modify: `.claude-plugin/marketplace.json:12`

**Interfaces:**
- Consumes: the documented plugin versioning policy in `docs/claude-skills.md` and approved design `docs/superpowers/specs/2026-08-05-v0.2.0-release-prep-design.md`
- Produces: matching `0.2.0` version strings for the standalone plugin manifest and marketplace plugin entry

- [ ] **Step 1: Run the focused version check and verify the old metadata fails**

Run:

```bash
python3 - <<'PY'
import json
from pathlib import Path

plugin = json.loads(Path(".claude-plugin/plugin.json").read_text())
marketplace = json.loads(Path(".claude-plugin/marketplace.json").read_text())
entries = [entry for entry in marketplace["plugins"] if entry["name"] == "navaris-cli"]

assert len(entries) == 1, f"expected one navaris-cli marketplace entry, found {len(entries)}"
assert plugin["version"] == "0.2.0", f"plugin version is {plugin['version']!r}"
assert entries[0]["version"] == "0.2.0", f"marketplace version is {entries[0]['version']!r}"
assert plugin["version"] == entries[0]["version"], "plugin versions do not match"
PY
```

Expected: FAIL with `AssertionError: plugin version is '0.1.0'`.

- [ ] **Step 2: Apply only the two version replacements**

Run:

```bash
python3 - <<'PY'
from pathlib import Path

for filename in (
    ".claude-plugin/plugin.json",
    ".claude-plugin/marketplace.json",
):
    path = Path(filename)
    old = path.read_text()
    needle = '"version": "0.1.0"'
    assert old.count(needle) == 1, f"{filename}: expected exactly one old version"
    path.write_text(old.replace(needle, '"version": "0.2.0"'))
PY
```

Expected diff in each file:

```diff
-  "version": "0.1.0",
+  "version": "0.2.0",
```

Indentation differs naturally by nesting depth; no surrounding JSON content changes.
